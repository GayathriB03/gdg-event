# Challenge Rules for Participants

- Work in teams of 2–3.
- Time limit: 45–60 minutes.
- You may use official documentation and browser DevTools.
- Do not edit the challenge validation criteria.
- Do not hardcode the unlock code or bypass Firebase/Gemini.
- A volunteer must see a successful sign-in, Firestore event list, Gemini response and unlock code.
- Be ready to explain two fixes.
